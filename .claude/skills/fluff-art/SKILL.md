# 毛团的外观规范

现在的皮肤都在 `renderer/skins/`，接口一样（`make(canvas, opts)` 返回 `{S, hit, petAt, geometry, spawn, setMouth, setMood, poke, land, spin, destroy}`）：

- 手绘（矢量）：`fluff.js` 毛团（下面这份规范主要说它）、`jelly.js` 水母、`slime.js` 史莱姆、`ghost.js` 小幽灵、`robot.js` 小机器人。后三个基于 `vectorBase.js`（共用状态机 / 眨眼 / 小动作 / 粒子 / 脸部件），只写身体和脸。
- 像素：`pixelFamily.js` 引擎 + `sprites.js` 图纸。`blob` 是照着用户给的参考图做的：平涂紫色 `#8360F7`、两个 2×2 的黑方块眼睛、平时没有嘴、没有腮红、**没有方框**（用户明确不要方框）。其它像素图纸：pjelly / pcat / pghost / probot / pslime。嘴只在说话、打哈欠时出现。

交互动画（所有皮肤都要响应）：摸 = 毛/格子/涟漪 + 爱心；抱走 = 脚晃、表情开心；甩出去 = 主进程做抛物线和弹跳，落地时 `land(k)` 压扁；双击 = `spin()`；AI 跑完 = 蹦一下 + 爱心 + 气泡。

调皮肤最快的办法：`python3 -m http.server 8766 --directory renderer`，浏览器开 `pet.html?skin=ghost`，控制台里 `__pet.useSkin("slime")` 随时切。

新皮肤加到 `renderer/skins/index.js` 和 `main/index.js` 的 `SKIN_LIST`。

毛团是一团羊毛毡质感的圆毛球：圆、软、暖、有两只小耳朵和一双小短腿。它不是猫、不是狗，不要加尾巴、胡须、鼻子。渲染代码在 `renderer/fluff.js`，全部用 Canvas 2D 程序化绘制，不用图片。

## 材质：羊毛毡

- **三层毛 + 内层绒**：底层长而暗、透明度低（体积感）；中层是主色，长度中等，色调随机在 a/b/c 三档之间；顶层短而亮，只画受光面（左上）；内层绒毛画在身体内部，极低透明度，让表面像毡子一样"密"。
- **每根毛是二次贝塞尔曲线**，不是直线。控制点跟着"流向"偏移：轻微随时间摆动（`sin(t + wob)`），底部的毛往下垂，耳朵附近的毛跟着耳朵抖，被摸的地方毛顺着手的方向倒伏并变短。
- **颜色**：主色 `#EBCB8E`（麦色羊毛），中 `#D2A85F`，深 `#A67C3E`，高光 `#F7E3B0`，眼皮 `#D9B36A`。身体是径向渐变（左上亮 → 右下暗），不要平涂。
- 影子是径向渐变的椭圆，蹦起来时缩小变淡。

## 比例

- 身体半径 R ≈ 窗口宽度的 21%；眼距 0.62R；眼睛在身体中线上方 0.08R；嘴在眼睛下方 0.27R；腮红在眼睛外侧 0.55R、略低。
- 耳朵是轮廓上的两个高斯鼓包（角度 -2.20 与 -0.94 弧度），高度 0.26R。不要画成三角形贴上去。
- 脚是两个椭圆垫在身体下沿 0.90R 处，被身体压住一半。

## 表情

- **眼睛**：深色椭圆珠子 + 两点高光（左上大、右下小）。眨眼是眼皮（身体色）从上往下盖，不是把眼睛压扁。开心时眼睛轻微眯（高度 ×0.65）并且腮红加深。
- **闭眼**有两种：睡觉 / 打哈欠是向上的弧（︶），开心到闭眼是向下的弧（︵）。
- **嘴**：默认是 ω 形小嘴；说话时是随音量开合的椭圆（音量来自音频分析器 RMS，不是随机抖动）；打哈欠是大 O；想事情是一条歪线；睡觉是小圆点。
- **腮红**永远有一点（alpha 0.16），开心时到 0.45。

## 动作（小动作是"活着"的关键）

- 呼吸：纵向 ±1.2%、横向反相 0.8%，睡觉时变慢。
- 每 4–11 秒随机一个小动作：东张西望（视线换 2–3 个点）、打哈欠（闭眼 + 大嘴 + 微伸展）、伸懒腰（横向拉宽 10%、纵向压 7%）、单边耳朵抖、左右扭一扭。
- 蹦：抛物线起跳，落地有 squash（横向 1.14 后弹回），脚在空中缩起来。
- 被抱走（拖动）时脚会晃，表情开心。
- 视线永远轻微跟着鼠标。
- 所有变化都用缓动（`x += (target - x) * min(1, dt*k)`），不要瞬变。

## 气泡

- 在它头顶，圆角 15px，纸色底（深色模式换深底），小尾巴指向它。宋体，14px。
- 它自己说的短句用打字机（28ms/字）；脑子流式输出的话直接整段刷新（不要打字机，会跟不上）。
- 说完后停留 3.5s + 90ms/字再收起；正在念长文时不收。

## 打磨流程

1. 改 `renderer/fluff.js`。
2. `MAOTUAN_SHOT=1 npx electron .` 会在 `.shots/` 生成 `pet.png`（透明背景）和面板截图；`MAOTUAN_ICON=1 npx electron .` 会把它渲染成 1024px 的 `assets/icon.png`（应用图标，打包时自动转 icns）。跑之前先 `pkill -f maotuan/node_modules/electron`，不然被单实例锁挡住。
3. 用 Read 看图，对照下面清单：
   - 毛的边缘有没有"锯齿感"（应该是柔软的、有长短差的绒边，不是均匀的刺）
   - 受光面和背光面分得清吗
   - 眼睛高光在不在、两点大小是否有别
   - 嘴有没有跟声音动（放一句试听看）
   - 站着不动 10 秒有没有至少一个小动作
   - 深色 / 浅色桌面上气泡都看得清吗
4. 不满意就只改一个变量再截一次。不要一次改一堆。

## 不要做的事

- 不要加装饰（蝴蝶结、帽子）除非用户要。
- 不要用 emoji 或图片替代绘制。
- 不要让它"死"或"生病"；情绪只在 idle / happy / sleepy / thinking / reading 之间。
- 不要用技术梗给它配台词。
